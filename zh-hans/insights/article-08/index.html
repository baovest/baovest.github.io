第五步——决策与风险管理

  • 首页 /
  • 洞察：AI 辅助投资工作流程 /
  • 第五步——决策与风险管理

大多数投资者分析能力还不错,却恰恰在这一步卡住:“我做了这么多工作——接下来该怎么办?“简单的"买入/卖出/持有"评级是不完整的。它没有说明该买多少、什么时候卖,也没有说明风险如何在过程中被管理。一个专业的决策,总会回答五个问题:

  1. 我要不要投资?(是/否/等待)
  2. 投多少?(仓位大小,占投资组合的百分比)
  3. 什么时候?(现在、分批建仓,还是等待某个具体的入场点)
  4. 退出计划?(止损、止盈,还是时间限制)
  5. 监控什么?(你会跟踪什么、多久检查一次)

“英伟达是个买入标的"和"英伟达以5%的仓位买入,在450到500美元之间分批建仓,如果利润率跌破65%或股价下跌20%就退出,从650美元开始分批止盈"之间的差距,正是业余决策和专业决策之间的全部区别。

仓位大小:信心水平乘以风险回报

仓位大小应该同时反映两个变量,而不是只看其中一个。高信心但风险回报不佳,可能意味着过度自信;风险回报有利但信心不足,可能意味着你漏掉了什么。两者兼备,才能支撑更大的仓位:

高信心 + 风险回报有利     → 10%-15% 仓位
高信心 + 风险回报一般     → 7%-10% 仓位
中等信心 + 风险回报有利   → 5%-7% 仓位
中等信心 + 风险回报一般   → 3%-5% 仓位
低信心(不论风险回报如何)→ 0%-2% 仓位,或放弃

生成建议的提示词模板:

基于以下对 [公司] 的分析:

**多头论点**:[总结——上行空间、概率]
**空头论点**:[总结——下行风险、概率]
**当前信心水平**:[高/中/低]
**我的风险承受能力**:[保守/稳健/激进]
**投资组合背景**:[总资产规模、现有仓位、行业敞口]

请建议:
1. 合适的仓位大小(占投资组合的百分比)
2. 这个仓位大小的理由
3. 这是核心仓位还是卫星仓位?
4. 应该一次性建仓还是分批买入?

对于一份显示英伟达信心中等、且当前价位风险回报略偏不利的多空综合判断,这会得出一个具体、有依据的数字——不是"适中”,而是类似"投资组合的3%到5%",分两批建仓(先建立一部分初始仓位,只有当股价回调至某个明确的支撑位时才加仓剩余部分)。

在入场前就设定好退出条件

把纪律性投资和抱有侥幸心理区分开的唯一习惯,就是在买入之前、而不是之后,定义好退出条件:

为我的 [公司] 投资设计退出触发条件:

**投资论点**:[用一句话概括你持有它的原因]
**关键多头前提**:[论点成立需要哪些条件持续为真]
**关键空头风险**:[什么会让论点失效]

请提供:
1. **基本面退出触发条件**:哪些业务指标或事件会表明论点已经失效?
2. **技术止损位**:什么价位代表不可接受的损失?(通常为下跌15%-25%)
3. **基于时间的复核**:如果情况没有变化,应该在什么时候重新评估?(例如6个月后)
4. **止盈策略**:在什么价位应该分批止盈?
5. **移动止损**:随着股价上涨,是否应该使用移动止损?

一份完整的退出计划有两个相互独立的部分。下行部分是一个技术止损位(通常在入场价下方15%-25%),加上明确命名的基本面触发条件——比如"如果同比营收增长跌破20%就退出”,或"如果毛利率跌破65%就退出”——这些条件要具体到可以在每次财报发布后机械地核对,而不是模糊到日后可以为自己找借口绕过去。上行部分是一个分批止盈计划:在一个目标价卖出三分之一仓位,在更高的目标价再卖出三分之一,如果论点依然成立就让剩余部分继续持有——在不强迫自己猜测确切顶部的前提下锁定收益。

常见的仓位大小指引

作为一个一般性(而非普适性)的框架:

核心仓位(高信心,低风险):        每个仓位 8%-15%
成长仓位(高信心,较高风险):      每个仓位 5%-10%
投机仓位(中/低信心):             每个仓位 2%-5%
试验/学习性仓位:                 每个仓位 1%-2%

单一行业上限:25%-30%
单一股票上限:15%-20%

以及几个值得养成习惯的风险管理默认设置:止损设在入场价下方15%-25%;盈利达到2倍时先获利了结25%-50%,让剩余部分继续持有;任何增长到占投资组合约20%以上的仓位,都应减仓回到15%左右;单笔交易判断错误时,承担的损失永远不超过投资组合总值的2%-3%。

把整个流程串起来的文件:投资备忘录

走完这个流程之后,把它写进一页纸的备忘录——未来的你会忘记今天的推理过程,而文档记录正是让你日后真正能从结果中学习、而不是事后为自己找理由的关键。

AI 在这里能做什么,不能做什么

AI 确实能帮你搭建决策框架、根据你提供的参数计算仓位大小、基于你自己陈述的论点提出退出触发条件,并进行情景分析。它不能告诉你个人的风险承受能力,不能确定地预测未来,也不能替你做最终决定——这份责任,是刻意留给你自己的。

一份可反复使用的清单

在投入资金之前,让每一项投资都通过同样简短的关卡:

  • 我能用一句话清晰地陈述我的论点
  • 我认真生成并对待了多头论点和空头论点
  • 我为多头/基准/空头三种结果分配了大致的概率
  • 我的仓位大小同时反映了信心水平和风险回报比——而不只是信心
  • 我在入场之前就设定好了止损位、止盈计划和明确命名的基本面退出条件
  • 我知道自己在监控什么,以及监控的频率
  • 我写了一页备忘录,即便交给别人看,他们也能理解这个决定

如果你会因为向别人解释这个决定而感到不自在,或者你无法回答"什么情况下我会卖出",这就是一个信号,提醒你在行动前先放慢脚步,而不是事后才反思。

好的流程并不能保证任何一笔交易都有好结果——即便是一套运行良好的流程,长期来看能维持55%到60%的胜率就已经很不错了。它能保证的是,你的决策是可重复、可复核、可改进的,而这正是按这种方式做分析、而不是凭直觉做决定的全部意义所在。
